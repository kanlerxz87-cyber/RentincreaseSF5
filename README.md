# Rent Increase SF — Outer Sunset (ZIP 94122)

Research and a public dashboard answering one question properly: **what does it actually take to raise rent lawfully on two rent-controlled San Francisco units, and how much can the rent go up?**

**Live site:** https://kanlerxz87-cyber.github.io/RentincreaseSF5/

---

## The finding that leads

The owner read that the Rent Board must be informed and a licence obtained. The requirement is real — the mechanism is different from what most secondary sources describe.

- There is **no licence application** and nothing is sent to the Rent Board in advance of notifying tenants.
- Reporting each unit in the Rent Board **Housing Inventory** (annual, free, due March 1) **auto-generates the rent increase licence** for a tenant-occupied unit.
- The licence must be **in effect on the effective date of the increase**, not merely by the time the notice is written. Without it the licence is suspended for the period of noncompliance and the tenant is not obligated to pay the increase.
- Being an individual owner rather than a corporation **changes nothing**: Chapter 37 applies to "owners", with no entity or size threshold.

Sources: SF Admin Code §37.15 · Rent Board Housing Inventory page · Rent Board rent-increase guidance.

## Verification rules used

1. Official sources only — `sf.gov` (including Rent Board forms and the Chapter 37 ordinance PDF), `leginfo.legislature.ca.gov`, `hud.gov` / `huduser.gov`, `data.sfgov.org`.
2. Every table row carries a source tag that resolves to the exact document on the Sources page.
3. If a value could not be confirmed it was **left empty and flagged** — never inferred. See the Flagged for Review page.
4. Anything that is reasoning rather than law is labelled **Analysis** and excluded from the verified count.

## Privacy

This repository is public, so no personal information is stored in it. Tenant names are replaced with letters (Tenant A–F); there is no address, no initials and no contact information. Dates and amounts are unchanged, because they carry the legal meaning. Full identifiers remain with the owner only.

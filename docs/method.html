Method

How this was built, and what it cannot do

Verification protocol

  1. Primary sources only. City ordinance text and Rent Board publications, California statutes on leginfo, HUD pages, and the City's open-data API. Secondary commentary was used only to generate questions, never to answer them.
  2. Read the text, not the summary. Where a page summarised a rule, the underlying section was pulled. Example: the 1.6% figure comes from Form 571 and is corroborated by §37.3(a)(1); the banking rule came from §37.3(a)(2) in the ordinance PDF, which is where the conflict with the website text showed up.
  3. Row-level citation. Every row carries a tag that resolves to the exact document on the Sources page, with a note stating what that document verifies.
  4. No fill-ins. If a value could not be confirmed it was left out of the tables. It is on the Flagged for Review page instead. That includes the federal rent ceiling question, the ACS median, and the HUD FMR figures.
  5. Arithmetic is generated, not typed. Percentages live in data/units.json with their Form 571 source; build.py multiplies them against the base rents. There is no hand-entered dollar figure in the data files.

Privacy handling

  • This repository is public, so personal information is not stored in it. Tenant names are replaced with letters (Tenant A-F). No address, no initials, no dates of birth, no contact details.
  • Dates and amounts are kept exactly as supplied, because they carry the legal meaning.
  • Nothing in this project was published to any third-party service; the site is static files served by GitHub Pages.

Known limits

  • Coverage is assumed, not proven. The 1940 build year and the unit count are your inputs (FL-02). If either unit is a single-family home or condominium, the local cap does not apply at all.
  • Base rents are your inputs (FL-01). Every dollar figure inherits any error in them.
  • Banking has an unresolved conflict inside official guidance (FL-03).
  • Market context is neighbourhood-level and self-reported, not ZIP-level and not asking rents (FL-04).
  • This is not legal advice and no attorney-client relationship exists. The Rent Board counsellor line (415-252-4600) answers these questions for free; a landlord-tenant attorney should review anything before a notice is served.

Reproducing the build

Static site, no dependencies: python3 build.py writes docs/ from data/*.json. python3 tools/check_links.py verifies every internal link and every external row URL.
